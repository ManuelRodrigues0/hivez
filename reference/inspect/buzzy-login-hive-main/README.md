# Hivez Bee Welcome

🐝 Hivez Login & Signup Page – Production-Level Premium UI Prompt

Create a world-class, production-ready Login & Signup page for Hivez, inspired by the playful quality of Duolingo, the smoothness of Linear, and the premium feel of Apple.

Use the uploaded bee mascot as the only character. Preserve its exact design, colors, proportions, and cute personality. The bee should feel alive, polished, and emotionally expressive.

Overall Design

- Ultra-modern UI with a clean premium aesthetic.

- Dark theme using Hivez colors:

  - Background: #071A2B

  - Primary: #0EA5E9

  - Secondary: #14B8A6

  - White cards with subtle transparency.

- Soft glassmorphism.

- Rounded corners (20-24px).

- Beautiful shadows.

- Smooth gradients.

- Tiny floating particles.

- Soft ambient lighting.

- Responsive on desktop, tablet and mobile.

- Every interaction should run at 60 FPS.

Bee Idle Animation

When page loads:

The bee slowly floats up and down.

- Wings flap gently.

- Eyes blink every 4–6 seconds.

- Antennas bounce naturally.

- Tiny pollen particles float around.

- Bee occasionally looks toward the login form.

Animation must feel alive but never distracting.

---

Login Button Interaction

Initially:

The bee is comfortably sitting on top of the Login button.

Its legs slightly dangle over the edge.

Small idle bounce every few seconds.

When user hovers Login:

- Bee becomes excited.

- Eyes become slightly larger.

- Wings flutter faster.

- Tiny happy bounce.

When user clicks Login:

Create an adorable animation sequence:

1. Bee jumps high.

2. Tiny squash and stretch.

3. Wings flap rapidly.

4. Small sparkle trail appears.

5. Bee lands back on button with soft bounce.

Use Disney-quality easing.

---

Password Field Animation

When cursor enters Password field:

The bee notices the user.

It flies beside the password box.

As the user types:

🐝 Bee immediately covers its eyes using both tiny front legs.

Requirements:

- Eyes completely hidden.

- Cute embarrassed expression.

- Tiny wing movement while waiting.

- Gentle idle bouncing.

- Occasionally peek for 0.2 seconds then quickly cover eyes again.

- Never reveal typed password.

When typing stops:

Bee slowly uncovers eyes.

Smiles happily.

Returns to idle.

---

Login Success Animation

If login succeeds:

Create a cinematic animation.

Sequence:

1. Button transforms into success state.

2. Bee jumps into the air.

3. Wings flap quickly.

4. Large confetti burst.

5. Colorful paper pieces fall naturally.

6. Sparkles appear.

7. Bee spins once.

8. Makes a happy loop in the air.

9. Leaves a glowing trail.

10. Gives a thumbs up (or happy waving gesture).

11. Smiles with sparkling eyes.

Duration:

2–3 seconds.

Then redirect smoothly.

---

Login Failure Animation

If credentials are incorrect:

Bee reacts sympathetically.

Sequence:

- Bee tilts its head.

- Sad eyes.

- Tiny sweat drop.

- Gentle shake of head.

- Points toward incorrect field.

- Error message slides in smoothly.

No aggressive shaking.

Make it encouraging.

---

Signup Page

Use the same premium design.

Fields:

- Full Name

- Email

- Password

- Confirm Password

Bee interaction:

While entering Name:

Bee happily waves.

While entering Email:

Bee follows the cursor.

While entering Password:

Bee covers eyes again.

While Confirm Password matches:

Bee gives excited thumbs up.

If passwords don't match:

Bee looks confused.

Small question mark appears above head.
